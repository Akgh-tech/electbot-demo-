# 🗳️ ElectBot — Democracy Learning System

An AI-powered interactive election education platform built for Hack2Skill.

## 🌐 Live Demo
https://akgh-tech.github.io/electbot-demo-

## ✨ Features
- 💬 AI Chatbot powered by Claude
- 🌐 3D Election Simulator (Three.js)
- 📊 FPTP vs PR vs Ranked Choice comparison
- 🌍 Google Translate (12 languages)
- ♿ Fully accessible (ARIA compliant)

## 🏆 Judging Criteria Met
- ✅ Code Quality — Modular architecture
- ✅ Security — Input sanitization, no exposed keys
- ✅ Efficiency — Lazy loading, debounced inputs
- ✅ Testing — Unit test suite included
- ✅ Accessibility — Keyboard nav, ARIA labels
- ✅ Google Services — Translate widget

## 🛠️ Tech Stack
- HTML5, CSS3, Vanilla JS
- Three.js (3D visualization)
- Claude AI (Anthropic)
- Google Translate API
